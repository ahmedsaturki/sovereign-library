# Threat Modeling — STRIDE + PASTA

**Status:** Phase-3 / Continuity-Hardening Wave

Sovereign cubes with security-sensitive surfaces carry both:

- A **STRIDE** report (per-cube, one page) — categorises threats by
  Spoofing, Tampering, Repudiation, Information Disclosure, Denial
  of Service, Elevation of Privilege.
- A **PASTA** report (per-cube, attacker-perspective) — Process for
  Attack Simulation and Threat Analysis: defines business objectives,
  technical scope, application decomposition, threat analysis,
  vulnerability analysis, and risk analysis.

Reports are generated by `scripts/threat-model.mjs` from the DSL
under `stride/` and `pasta/`. The DSL is YAML for human review.

## Conventions

- Each cube gets one STRIDE and one PASTA report.
- Each report is one Markdown file with a strict template; deviations
  require ADR.
- Reports are regenerated by `scripts/threat-model.mjs` and reviewed
  in PR.
