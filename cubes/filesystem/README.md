# Filesystem Cube v0.1

Standalone filesystem capability using only Node.js standard-library filesystem and path primitives.

## Scope

- text and binary read/write
- append
- atomic replacement
- exists/stat
- directory listing
- mkdir
- copy/move/remove
- root containment checks
- read/write byte limits
- deterministic typed errors

## Non-goals

No database, cloud-storage SDK, virtual filesystem, or framework dependency.

## Dependency policy

Runtime third-party dependencies: **0**.
