# Sovereign Library — Project Memory Policy v1.0

GitHub is the permanent project memory and system of record.

All meaningful work must be persisted to the repository. Default evolution is additive. Preserve existing functionality, contracts, history, compatibility, decisions, and evidence. Any supersession, deprecation, deferment, archive, or removal must preserve the historical reason.

Recovery starts from `AGENTS.md`, `PROJECT_CONTROL.md`, `ROADMAP.md`, the architecture and knowledge documents, and live GitHub state. Chat history is not authoritative.

A meaningful milestone is durable only after:

`CHANGE → TEST → DOCUMENT → COMMIT → PUSH → VERIFY REMOTE`

Current state must always be reconciled against live GitHub. Stale SHAs or old reports never override live repository state.
