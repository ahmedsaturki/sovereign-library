# Project Memory Rules

These rules complement `AGENTS.md` and are intentionally simple.

- GitHub is the durable system of record.
- Important work must be persisted to GitHub.
- Default evolution is additive.
- Preserve history and compatibility.
- Never leave meaningful completed work only in chat or local state.
- Verify live GitHub before trusting documented current-state identifiers.
- Keep one authoritative home for each concern.
- Record the active task, completed work, deferred work, blockers, and next task.
- A milestone is durable only after documentation, commit, push, and remote reconciliation.
