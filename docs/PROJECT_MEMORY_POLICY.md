# Sovereign Library — Project Memory Policy

GitHub is the permanent project memory.

All meaningful work must be persisted to the repository. Default evolution is additive. Preserve existing functionality, contracts, history, compatibility, decisions, and evidence. If something must be superseded, deprecated, deferred, archived, or removed, record why and preserve the historical context.

Recovery starts from `AGENTS.md`, `PROJECT_CONTROL.md`, `ROADMAP.md`, the architecture/knowledge documents, and live GitHub state. Chat history is not authoritative.

A meaningful milestone is durable only after:

`CHANGE → TEST → DOCUMENT → COMMIT → PUSH → VERIFY REMOTE`

Current state must always be reconciled against live GitHub. Stale SHAs or reports must never override live repository state.
