# Continuity Quick Reference

Sovereign Library is maintained as a durable GitHub-first project.

**Recovery:** `AGENTS.md → PROJECT_CONTROL.md → ROADMAP.md → architecture → knowledge → live GitHub → relevant SPEC`.

**Permanent rules:** evolve additively; preserve history and compatibility; persist meaningful decisions; commit and push completed milestones; verify the remote; do not rely on chat history.

**Architecture:** `INDEPENDENT CUBES → EXPLICIT COMPOSITION → REAL PRODUCTS`.

**Distribution:** GitHub-only at the current project stage; external registries are deferred by policy.
