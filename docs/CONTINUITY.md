# Sovereign Library — Continuity Contract

GitHub is the durable project memory. Meaningful decisions, implementation changes, verification evidence, blockers, deferred work, and current tasks must be persisted to the repository.

The default evolution model is additive: add, extend, harden, improve, supersede, deprecate, archive, or defer before deleting or silently replacing existing work. Preserve historical context.

Recovery order:

`AGENTS.md → PROJECT_CONTROL.md → ROADMAP.md → architecture/knowledge docs → live GitHub → relevant SPEC/release records`

A meaningful milestone is durable only after:

`CHANGE → TEST → DOCUMENT → COMMIT → PUSH → VERIFY REMOTE`
