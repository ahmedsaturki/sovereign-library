# Sovereign Library — Project Memory Rules v1.0

This is a permanent repository-level companion to `AGENTS.md`.

- GitHub is the persistent memory and system of record.
- Meaningful decisions and completed work must be persisted.
- Evolution is additive by default; preserve capabilities, compatibility, history, and evidence.
- Do not silently delete or replace existing functionality or knowledge.
- Verify live GitHub before trusting documented current-state identifiers.
- Keep one authoritative home for each concern.
- A meaningful milestone requires documentation, commit, push, and remote reconciliation.
- Record current task, completed work, deferred work, blockers, and next task.
- Do not depend on chat history for recovery.
