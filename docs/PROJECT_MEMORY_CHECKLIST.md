# Project Memory Checkpoint Checklist

Use this before ending any meaningful work session.

## State

- [ ] Current GitHub main SHA verified
- [ ] Current feature branch verified
- [ ] Current PR HEAD verified
- [ ] Working tree clean or intentionally documented
- [ ] Current CI for the relevant commit verified

## Knowledge

- [ ] Completed work recorded
- [ ] Preserved work recorded
- [ ] Deferred work recorded
- [ ] Blockers recorded
- [ ] Current official task recorded
- [ ] Exactly one next task recorded

## Engineering

- [ ] Relevant tests executed
- [ ] Security verified
- [ ] Package state verified
- [ ] Documentation synchronized
- [ ] No hidden monorepo coupling introduced
- [ ] No unrelated feature started

## Persistence

- [ ] Changes committed
- [ ] Commit pushed to GitHub
- [ ] Remote branch reconciled
- [ ] No important work remains only in local state or chat

## Preservation

- [ ] No capability was silently deleted
- [ ] No historical evidence was erased
- [ ] No public API was silently removed
- [ ] Any supersession/deprecation/removal is documented
