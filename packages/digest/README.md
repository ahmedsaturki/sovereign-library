# Digest / Hash Cube v0.1

Native integrity helpers built on Node.js `node:crypto` with zero runtime third-party dependencies.

## Included

- SHA-256 and SHA-512
- HMAC-SHA256 and HMAC-SHA512
- hex and byte outputs
- bounded synchronous input sizes
- bounded AsyncIterable hashing
- constant-time comparison for same-length byte sequences
- deterministic typed errors
- immutable configuration snapshots
