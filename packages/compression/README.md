# Content-Encoding / Compression Cube v0.1

Native bounded compression/decompression helpers for gzip and deflate.

Built on Node.js `node:zlib` runtime primitives with zero runtime third-party dependencies.

## Included

- gzip sync/async compression and decompression
- deflate sync/async compression and decompression
- generic format helpers
- bounded input/output sizes
- decompression output guard
- immutable configuration snapshots
- deterministic typed errors
- string and byte inputs
